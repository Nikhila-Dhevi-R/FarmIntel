# FarmIntel
AI-Powered Farmer Query Support and Community Crop Outbreak Intelligence System

FarmIntel combines LLM-based agricultural query answering, verified knowledge retrieval, confidence-based human escalation, pesticide safe-harvest calculation, and community outbreak detection. Using a normalized relational database, multi-table JOINs, and database triggers, farmer queries become regional intelligence that identifies recurring pest or disease patterns and generates timely early-warning alerts for nearby farming communities.
